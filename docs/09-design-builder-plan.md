# 9. แผน: ให้ผู้ใช้ประกอบหน้าตาคลิปเองหลังสัมภาษณ์ (ยังไม่ได้ทำ)

สถานะ: **แผน** — ทำในแชทใหม่ เริ่มจาก "ส่วนที่ 1 หัวข้อ" ก่อน ให้เจ้าของงานดูของจริงแล้วค่อยทำส่วนถัดไป

## ทำไมเปลี่ยนแผน

ลองทำ `templates/talking-head/` 10 แบบแล้ว (themes.json + themes.css) เจ้าของงานตอบว่า **ไม่ใช่**:
- ทั้ง 10 แบบใช้โครงเดียวกัน ต่างแค่สี ฟอนต์ กรอบ → ดูเหมือนกันหมด
- ภาพตัวอย่างใช้หุ่นจำลอง ดูไม่ออกว่าเหมาะกับธุรกิจไหน
- ต้องการ: ผู้ใช้เห็นแล้วรู้ว่าเหมาะกับแบรนด์ตัวเอง, สวย, หลากหลาย "รูปแบบ" ไม่ใช่แค่สี

ทางใหม่: แทนที่จะให้เลือกเทมเพลตสำเร็จรูป ให้ **ถามทีละส่วน** แล้วประกอบเป็นเทมเพลตของแบรนด์นั้น

## หมวดใหม่ในการสัมภาษณ์ (ต่อจากหมวด 6 ใน 07-onboarding.md)

ถามด้วย AskUserQuestion ส่วนละ 1–2 ข้อ ทุกตัวเลือกมี `preview` เป็นภาพร่างง่ายๆ (ตำแหน่ง/กรอบ/ตัวอักษรบนจอแนวตั้ง)
ทุกข้อมีทางเลือก "พิมพ์บอกเอง / ส่งรูปที่ชอบ" + `ข้ามไว้ก่อน` / `ไม่สะดวกตอบ` ตามกติกาเดิม

| ส่วน | คำถาม | ตัวเลือก (3–4 แบบ) |
|---|---|---|
| 1. หัวข้อ | หัวข้อแบบไหน | ป้ายมีกรอบมุมซ้ายบน · ตัวใหญ่กลางจอไม่มีกรอบ · แถบเต็มความกว้าง · ป้ายเอียงแบบสติกเกอร์ |
| | หัวข้อเข้ามาแบบไหน | เลื่อนเปิดจากซ้าย · เด้งขึ้น · พิมพ์ทีละตัว · จางเข้า |
| 2. ซับ | ซับแบบไหน | กล่องเข้มโปร่ง · ตัวโตขอบดำไม่มีกล่อง · ไฮไลต์คำต่อคำ · แถบสีแบรนด์ |
| | เน้นคำสำคัญอย่างไร | สีแบรนด์ · ไฮไลต์พื้นหลัง · ตัวใหญ่ขึ้น · ขีดเส้นใต้ |
| 3. ช่วงกราฟิก | คนพูดอยู่ตรงไหน | วงกลมกลางจอ · แบ่งจอบน-ล่าง · กรอบเล็กมุมจอ · ไม่มีกราฟิก |
| | กราฟิกดูแบบไหน | ไอคอนเรียบ · การ์ดลอยมีเงา · ลายมือ/สติกเกอร์ · ตัวเลขใหญ่ |
| 4. เปลี่ยนช็อต | ต่อช็อตแบบไหน | ตัดตรง · ซูมเข้าเล็กน้อย · เลื่อนสไลด์ · แฟลชขาว |
| 5. ตอนจบ | จบอย่างไร | การ์ดโลโก้พื้นเรียบ · ฟุตเทจเล่นต่อ + การ์ดจองคิวทับ · ภาพหยุดนิ่ง + ปุ่มจอง · ไม่มีการ์ด |
| | ปุ่มชวนแบบไหน | ปุ่มแคปซูล · ลูกศรชี้ลง "กดลิงก์" · ป้ายเบอร์โทร/LINE |

หลังเลือกครบ:
1. บันทึกตัวเลือกใน `brand.json` เช่น `"design": {"title": "corner", "title_in": "wipe", "caption": "box", ...}`
2. ทำภาพตัวอย่าง 4 ภาพจากคลิปจริงงานแรกของผู้ใช้ (หัวข้อ+ซับ / ช่วงกราฟิก / เปลี่ยนช็อต / ตอนจบ) ใช้ในงานของผู้ใช้เท่านั้น ห้ามขึ้น repo
3. ผู้ใช้สั่งแก้เป็นส่วนได้ ("หัวข้อเอาแบบ 2 แต่สีเข้มขึ้น") แล้วบันทึกใหม่
4. ถ้าผู้ใช้ส่งรูปสไตล์ที่ชอบ: ถอดสี ตำแหน่ง ขนาด รูปทรงกรอบ ทำเป็นแบบใหม่ของส่วนนั้น
   (ฟอนต์ที่ไม่มีใน @fontsource ใช้ฟอนต์ไทยใกล้เคียง ห้ามใช้โลโก้/ชื่อแบรนด์อื่น)

| ขั้น | งาน | เวลาโดยประมาณ |

## ของที่ทดลองไว้แล้ว (อยู่ใน repo ทดลอง `woothipongth-netizen/test3` branch `onboarding-profile`)

ใช้เป็นตัวอย่างได้ ถ้าจะใช้ให้ดึงเฉพาะไฟล์ที่ต้องการมา ไม่ต้องรวมทั้ง branch (มีข้อมูลร้านทดลองอยู่):
- `templates/talking-head/build.py`: หัวข้อ, ซับตำแหน่งเดียว (ใต้วงกลม เหนือ UI แอป), คนพูดย่อเป็นวงกลมตอนกราฟิกขึ้น,
  กราฟิกทั่วไป 6 ชนิด (grid cards bars steps checklist stat), การ์ดจบโลโก้หลังพูดจบ
- `scripts/setup.sh` ส่วนดึงฟอนต์ไทย 9 ตระกูล
- `docs/05-lessons.md` หัวข้อ "งานคลิปพูดหน้ากล้อง": ตัดช่วงเงียบ, ตารางท่อนพูดมีรหัสให้เจ้าของงานเลือกตัด, ซับไม่ทับหน้า

## ข้อจำกัดที่ต้องรู้

- เครื่อง cloud เข้าเว็บภาพ/คลิปฟรีไม่ได้ (pexels, pixabay, unsplash, wikimedia ถูกบล็อก)
  ถ้าต้องใช้ ให้เจ้าของงานเพิ่มโดเมนใน Network access ของ environment ก่อนเปิดแชท
- ภาพตัวอย่างห้ามใช้หุ่นจำลอง/ภาพวาดแทนคน (เจ้าของงานไม่ชอบ) ใช้ภาพร่างสำหรับตัวเลือก และคลิปจริงของผู้ใช้สำหรับภาพตัวอย่างสุดท้าย
- render ใช้ ~12 นาที / คลิป 2 นาที: ส่ง snapshot ให้ดูก่อนทุกครั้ง render ครั้งเดียว
