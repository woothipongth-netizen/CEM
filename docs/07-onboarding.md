## กติกาการถาม (สำหรับ Claude)

- ถามด้วยเครื่องมือถามแบบเลือกตอบ (AskUserQuestion) ครั้งละไม่เกิน 4 "หน้า" (1 หน้า = 1 คำถามในเครื่องมือ มีได้ 4 ตัวเลือก)
- **ทุกข้อต้องมีตัวเลือก `ข้ามไว้ก่อน` และ `ไม่สะดวกตอบ`** ยกเว้นข้อที่เขียนว่า **ไม่มีตัวเลือกข้าม** ช่องพิมพ์เอง (Other) มีให้อัตโนมัติ
  - `ข้ามไว้ก่อน` = บันทึกเป็น `⏳ รอคำตอบ` แล้วถามใหม่ตอนเริ่มงานที่ต้องใช้ข้อมูลนี้
  - `ไม่สะดวกตอบ` = บันทึกเป็น `— ไม่ระบุ` แล้ว **ห้ามถามข้อนี้ซ้ำ** ใช้ค่าเริ่มต้นแทน
- **ข้อที่เลือกได้หลายตัว** (เขียนว่า "เลือกได้หลายข้อ") ใช้ `multiSelect: true` และแบ่งตัวเลือกเป็นหลายหน้าในการถามครั้งเดียว:
  - หน้าแรก: ตัวเลือกหลัก 2 ตัว + `ข้ามไว้ก่อน` + `ไม่สะดวกตอบ`
  - หน้าถัดไป: ตัวเลือกเพิ่ม 3 ตัว + `ไม่เลือกเพิ่ม` (ให้ตอบหน้านั้นได้เสมอ)
  - หัวคำถามของหน้าถัดไปเขียนว่า "(ต่อ) ..." ให้รู้ว่าเป็นข้อเดียวกัน
- ข้อที่เป็นข้อความเฉพาะ (ชื่อร้าน ชื่อคน) บอกให้พิมพ์จริงในช่อง Other
- **ห้ามใส่ตัวอย่างที่มาจากคำตอบเดิมหรือร้านอื่น** ในคำถามและตัวเลือก (เช่น ชื่อเล่นคนพูด) ใช้คำกลางๆ เช่น "ชื่อเล่น + ครับ"
- **ห้ามถามข้อเลือกหลายหน้าข้ามการเรียกเครื่องมือ** ข้อ 3 หน้าต้องอยู่ในการเรียกเดียวกันทั้งหมด จัดชุดตาม "แผนการถาม" ด้านล่าง

### อ่านคำตอบข้อเลือกหลายหน้า

| เจ้าของตอบ | บันทึกเป็น |
|---|---|
| หน้าแรก `ข้ามไว้ก่อน`/`ไม่สะดวกตอบ` แต่หน้าถัดไปเลือกตัวเลือกจริง | ใช้ตัวเลือกจริง (ไม่นับการข้าม) และบอกในสรุปท้ายหมวด |
| ทุกหน้าเป็น `ข้าม`/`ไม่เลือกเพิ่ม` | ตามตัวข้ามของหน้าแรก |
| เลือก **4 ข้อขึ้นไป** ในข้อ 2.2 หรือ 4.2 | ถามต่อทันที 1 หน้า: "ข้อไหนสำคัญที่สุด" (ตัวเลือก = 3 ข้อที่เลือก + `เท่ากันหมด`) บันทึกข้อนั้นเป็นอันดับแรก |

|---|---|
| 1.3 ตอบ "หลายบริการ" | "พิมพ์รายการบริการที่โปรโมตบ่อย" (Other) + `ข้ามไว้ก่อน` · `ไม่สะดวกตอบ` |
| 3.4 เลือกเจ้าของร้าน/คนในทีม แต่ไม่ได้พิมพ์ชื่อ | ไม่ต้องถามแยก ใช้ชื่อจาก 5.2 บันทึกเป็น `staff_name` |
| 5.3 เลือก "ใส่เพลงเองในแอป" หรือ "ไม่ใช้เพลง" | ข้ามข้อ 7.2 |

| 5.3 | เพลงพื้นหลัง | ใส่เพลงเองในแอป (TikTok / IG) Claude ส่งคลิปไม่มีเพลง · ให้ Claude เลือกเพลงให้ (จากคลังของร้าน หรือ Mixkit ที่ใช้เชิงพาณิชย์ได้ และตัดภาพตามจังหวะ) (อื่นๆ: เลือกเพลงเองจากคลังทุกงาน, ไม่ใช้เพลง) | profile (ลิงก์คลังเพลงถามในข้อ 7.2) |
| 5.4 | มีคำหรือเรื่องที่ห้ามใส่ในคลิปไหม | มี (พิมพ์คำหรือเรื่องที่ห้ามในช่อง Other) · ไม่มีคำเจาะจง ไปต่อได้ — **ไม่มีตัวเลือกข้าม** และ **ห้ามเสนอคำให้** | profile (เช็กก่อนส่งงานทุกครั้ง) |

## หมวด 6: การทำงานร่วมกัน

| # | คำถาม | ตัวเลือก | บันทึกที่ |
|---|---|---|---|
| 6.1 | อยากคอยดูระหว่างทำงาน หรือให้ทำอัตโนมัติแล้วรอดูงานไฟนอล | **ดูระหว่างทาง** · **อัตโนมัติ รอดูงานไฟนอล** (ใส่คำอธิบายผลของแต่ละแบบในตัวเลือก ตามตารางด้านล่าง) — **ไม่มีตัวเลือกข้าม** | profile `โหมดการทำงาน` |
| 6.2 | ทำคลิปบ่อยแค่ไหน | สัปดาห์ละ 1–3 คลิป · ทุกวัน | profile |

คำอธิบายที่ต้องใส่ใน `description` ของตัวเลือก 6.1 (ให้เจ้าของเห็นผลของแต่ละแบบก่อนเลือก):

| ตัวเลือก | ได้อะไร | แลกกับ |
|---|---|---|
| ดูระหว่างทาง | เห็นแผนก่อน render รู้ว่าต้องแก้อะไร เห็นคำผิดในซับ เลือกเพลงได้ เปลี่ยนฟุตเทจได้ ก่อนเสียเวลา render | ช้ากว่า ต้องคอยตอบ |
| อัตโนมัติ รอดูงานไฟนอล | ไม่ต้องสั่งอะไรเลย Claude ตัดสินใจเอง ปล่อยงานทิ้งไว้ได้ ได้งานเร็ว | อาจต้องสั่งแก้บางส่วนหลังเห็นงาน (แก้แล้วต้อง render ใหม่) |

**จุดตรวจของโหมด "ดูระหว่างทาง"** (โหมดอัตโนมัติข้ามทุกจุด):
- ตัดคลิป: แผนช็อต + หัวข้อ + ซับ (คำที่ไม่แน่ใจ) ก่อน render ([04-workflow.md](04-workflow.md) ขั้น 3)
- ออกแบบเทมเพลต: ภาพตัวอย่างให้เลือกแบบก่อนสร้างจริง ([09-template-design.md](09-template-design.md))

โหมดอัตโนมัติ: Claude เลือกเองทุกจุด แล้วส่งงานไฟนอลพร้อมสรุปสั้นๆ ว่าเลือกอะไรไป
และ **บอกคำในซับที่เดาจากบริบทเสมอ** เจ้าของสั่งแก้หลังเห็นงานได้ เปลี่ยนโหมดได้ทุกเมื่อด้วยคำสั่ง "แก้โปรไฟล์"

**ไม่ต้องถามวิธีส่งงาน:** ส่งไฟล์ในแชท + หน้าปุ่มบันทึก (Artifact) เสมอ บันทึกค่านี้ในโปรไฟล์ให้เลย

## หมวด 7: แหล่งไฟล์และบัญชี

ถามที่อยู่ของไฟล์แยกเป็น 3 โฟลเดอร์ใน Drive ของเจ้าของเอง และถามเรื่องคีย์ ElevenLabs
repo นี้ **ไม่แจกเพลงหรือ SFX** (แหล่งส่วนใหญ่ห้ามแจกไฟล์ต่อ) เจ้าของใช้คลังของตัวเองเท่านั้น

| # | คำถาม | ตัวเลือก | บันทึกที่ |
|---|---|---|---|
| 7.1 | โฟลเดอร์ฟุตเทจใน Drive | ใช้โฟลเดอร์เดียวทุกงาน (วางลิงก์ใน Other) · ส่งลิงก์ใหม่ทุกงาน | `brand.json` footage_folder (ว่าง = ขอลิงก์ทุกงาน) |
| 7.2 | มีคลังเพลงใน Drive ไหม (ถามเมื่อ 5.3 เลือกคลังเพลง) | มี (วางลิงก์โฟลเดอร์ใน Other) · ยังไม่มี | `brand.json` music_library (ยังไม่มี = ขอไฟล์เพลงทุกงาน) |
| 7.3 | มีคลังเสียงเอฟเฟกต์ (SFX) ใน Drive ไหม | มี (วางลิงก์โฟลเดอร์ใน Other) · ยังไม่มี ใช้ SFX ในตัว (whoosh, sparkle) | `brand.json` sfx_library (ว่าง = ใช้ SFX ในตัว) |
| 7.4 | คีย์ ElevenLabs (ใช้สร้างเสียงเมื่อเจ้าของสั่ง) | มีคีย์ ใส่ในฟอร์มปลอดภัย · ยังไม่มี | **ไม่บันทึกใน repo** เก็บเป็นความลับของ environment |

- ตอนรับลิงก์ 7.1–7.3 เตือนเจ้าของสั้นๆ: ใช้เฉพาะเพลง/SFX ที่มีสิทธิ์ใช้ในคลิปเชิงพาณิชย์
- ถ้าดึงไฟล์จากคลังแล้วติดโควต้าดาวน์โหลดของ Drive: บอกเจ้าของให้ส่งไฟล์นั้นในแชทแทน

**คีย์ ElevenLabs (7.4):** ห้ามให้เจ้าของพิมพ์คีย์ในแชทหรือในแบบฟอร์ม
- ถ้ามีเครื่องมือ `request_credential`: เรียกด้วย host `api.elevenlabs.io`, header `xi-api-key` ระบบเปิดฟอร์มปลอดภัยให้เจ้าของใส่เอง Claude ไม่เห็นค่าคีย์
- ถ้าไม่มี: บอกเจ้าของเพิ่มคีย์เป็นความลับของเครือข่าย (network secret) ในหน้าตั้งค่า environment ของ Claude Code
- เช็กว่าใช้ได้ด้วยคำขอเล็กๆ 1 ครั้ง (เช่น ดูข้อมูลบัญชี) แล้วบันทึกในโปรไฟล์แค่ว่า "ElevenLabs: ตั้งค่าแล้ว"
