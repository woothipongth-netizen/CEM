# 9. ออกแบบเทมเพลตเฉพาะร้าน (ต่อจากการสัมภาษณ์ธุรกิจ)

ทุกร้านได้เทมเพลตที่ **ออกแบบใหม่ทั้งหมด ไม่เหมือนร้านอื่น** สร้างจาก **คำตอบทุกข้อ** ของเจ้าของร้าน
ทั้งการสัมภาษณ์ธุรกิจ ([07-onboarding.md](07-onboarding.md)) และคำถามออกแบบในไฟล์นี้
เทมเพลตต้นฉบับ (`templates/review-motion/`) **ไม่ใช่ฐานของการออกแบบ** ใช้เป็นแค่ข้อกำหนดทางเทคนิค (ดูหัวข้อสุดท้าย)

## ลำดับ

1. สัมภาษณ์ธุรกิจเสร็จ ([07-onboarding.md](07-onboarding.md))
2. **สรุปโปรไฟล์เป็นข้อกำหนดออกแบบก่อนถาม** (หัวข้อถัดไป) ไม่ถามซ้ำสิ่งที่รู้แล้ว
3. ถามคำถามออกแบบในไฟล์นี้ (6 หมวด)
4. Claude สรุปคอนเซปต์ 1 ย่อหน้า + ภาพตัวอย่างตามจำนวนที่เจ้าของเลือก ให้เลือกหรือสั่งแก้
   (โหมด "อัตโนมัติ" ในโปรไฟล์: Claude เลือกแบบที่ตรงโปรไฟล์ที่สุดเอง ไม่หยุดรอ แล้วส่งภาพตัวอย่างทุกแบบพร้อมงานจริงและบอกเหตุผล)
5. สร้างเทมเพลตจริงที่ `templates/<ชื่อร้าน>/` และบันทึกคำตอบที่ `design-brief.md`
6. เปิด PR ให้เจ้าของร้านดู แล้วใช้เทมเพลตนี้เป็นค่าเริ่มต้นของงานตัดคลิปทุกชิ้น

## ขั้นที่ 2: โปรไฟล์ → ข้อกำหนดออกแบบ (ห้ามข้าม)

บทเรียนจากการทดสอบ: ถ้าออกแบบจากคำตอบหมวดออกแบบอย่างเดียว ผลจะไม่ตรงธุรกิจ
(เช่น เจ้าของเลือกแนว **ก่อน-หลัง** แต่ภาพตัวอย่างออกมาเป็นคลิปให้ความรู้)
ก่อนถามคำถามออกแบบ ให้เขียนตารางนี้ลง `design-brief.md` และใช้ตรวจภาพตัวอย่างทุกรอบ:

| จากโปรไฟล์ | ใช้กำหนดอะไรในเทมเพลต |
|---|---|
| 4.2 แนวคลิป (แนวแรก = แนวหลัก) | **โครงของคลิปและช่วงไฮไลต์** เช่น ก่อน-หลัง → ต้องมีช่วงเทียบภาพก่อน-หลัง, ให้ความรู้ → ป้ายขั้นตอน/ข้อ, รีวิวลูกค้าพูด → ซับใหญ่ + ชื่อ/คำพูดลูกค้า |
| 2.2 สิ่งที่ลูกค้ากังวล | ประโยคเปิด 3 วินาทีแรก และข้อมูลประกอบที่ต้องโชว์ (เช่น กลัวผลไม่ดี → โชว์ผลงานจริงให้เร็ว) |
| 1.4 จุดเด่น | สิ่งที่กราฟิกต้องชี้ให้เห็น (ฝีมือ → ให้ภาพผลงานเป็นพระเอก) |
| 3.1 โทน | จังหวะ ทรานสิชัน ความหนักของตัวหนังสือ |
| 2.4 ปุ่มชวน | ท้ายคลิป |
| 4.1 แพลตฟอร์ม | พื้นที่ปลอดภัยจาก UI (ตำแหน่งหัวข้อ ซับ โลโก้) |
| 4.3 ความยาว | จำนวนช่วงหัวข้อ และความเร็วของแอนิเมชัน |
| 3.2 / 3.3 สี ฟอนต์ โลโก้ | สีแบรนด์ ฟอนต์ สัญลักษณ์ |
| 5.4 ข้อห้าม | สิ่งที่เทมเพลตต้องไม่มี (เช่น ห้ามเห็นหน้าลูกค้า → ป้ายและกราฟิกต้องไม่บังผลงาน แต่ต้องมีวิธีบังหน้าได้) |

**ภาพตัวอย่างทุกแบบต้องแสดงแนวคลิปหลักจริง** (ก่อน-หลัง ต้องเห็นช่วงก่อน-หลังในภาพตัวอย่าง) ถ้าเลือกหลายแนว ให้มีภาพของแต่ละแนว

## กติกาการถาม (สำหรับ Claude)

- ใช้ AskUserQuestion ครั้งละไม่เกิน 4 หน้า กติกาเดียวกับการสัมภาษณ์ธุรกิจ:
  **ทุกข้อมีตัวเลือก `ข้ามไว้ก่อน` และ `ไม่สะดวกตอบ`** · ข้อ "เลือกได้หลายข้อ" แบ่งหลายหน้า (หน้าแรก 2 ตัวเลือก + 2 ตัวข้าม, หน้าถัดไป 3 ตัวเลือก + `ไม่เลือกเพิ่ม`)
  - `ข้ามไว้ก่อน` = Claude ตัดสินใจแทนจากโปรไฟล์ธุรกิจ แล้วบอกเจ้าของร้านว่าเลือกอะไรไป
  - `ไม่สะดวกตอบ` = ไม่ถามซ้ำ ให้ Claude ออกแบบเองจากโปรไฟล์ธุรกิจ
- **ใส่ตัวเลือกให้ครบในหน้าตัวเลือก** ไม่ปล่อยให้เจ้าของต้องพิมพ์ใน "อื่นๆ" เอง (ช่อง Other มีไว้สำหรับกรณีพิเศษเท่านั้น)
- ตัวเลือกเป็น **ตัวอย่างความรู้สึก ไม่ใช่สไตล์สำเร็จรูป** ห้ามเสนอสิ่งที่เคยออกแบบให้ร้านอื่น
- ถ้าตอบว่าชอบแบบไหน ให้ถามต่อว่า "ชอบตรงไหน" แทนการลอกทั้งแบบ
- ไม่ถามซ้ำสิ่งที่รู้แล้วจากโปรไฟล์ (โทนหลัก สีแบรนด์ แนวคลิป)
- ห้ามใช้คำว่า "ช่าง" ในคำถามและตัวเลือก

## สิ่งที่ Claude ส่งมอบ

1. **`design-brief.md`**: ตารางโปรไฟล์ → ข้อกำหนดออกแบบ + คำตอบทั้งหมด + คอนเซปต์ 1 ย่อหน้า + เหตุผลของแต่ละการตัดสินใจ
2. **`templates/<ชื่อร้าน>/`**: เทมเพลตใหม่ (build.py + หน้า HTML + content.example.json) ออกแบบจากศูนย์ตาม brief
3. **ภาพตัวอย่าง** ก่อนสร้างจริง (แสดงแนวคลิปหลัก) และภาพ/คลิปจากเทมเพลตจริงหลังสร้าง ส่งในแชท (ไม่อัปขึ้น repo)
4. แก้ `business-profile.md` หัวข้อเทมเพลต ให้ชี้ไปที่เทมเพลตของร้าน

## ข้อกำหนดทางเทคนิคที่เทมเพลตใหม่ต้องทำตาม

หน้าตาออกแบบใหม่ได้ทั้งหมด แต่ต้องทำงานกับขั้นตอนเดิมได้ ([04-workflow.md](04-workflow.md)):

- **รับข้อมูลชุดเดิม:** `content.json` (hook, titles, captions, transitions, end_card และส่วนเพิ่มของแนวคลิป เช่น compare), ช็อตจาก `cut_shots.py` (`shots.json` + `--head-pad`), เสียงจาก `mix_audio.sh`, ชื่อ สี โลโก้จาก `brand.json`
- **คำสั่งเดิม:** `python3 -I templates/<ชื่อร้าน>/build.py <content.json> <โฟลเดอร์โปรเจกต์>`
- **ต้องมีหัวข้อค้างบนจอทุกช่วง** และซับอ่านได้บนพื้นสว่างและพื้นมืด
- **พื้นที่ปลอดภัยจาก UI** (จอ 1080×1920): เว้นบน 160px, ล่าง 380px, ขวา 140px ตั้งแต่กลางจอลงไป (ปุ่มกดถูกใจ/แชร์), ซ้าย 60px
  ซับ หัวข้อ โลโก้ ปุ่มชวน ต้องอยู่ในพื้นที่นี้ ถ้าลง Facebook ด้วย เว้นล่างเพิ่มเป็น 420px
- ไม่มีป้ายชื่อคนพูด (ไม่ใช้ `lower_thirds`)
- ฟอนต์จาก `brand.json` เท่านั้น เผื่อขอบบนให้วรรณยุกต์ไทย
- GSAP จากไฟล์ในเครื่อง ไม่ใช้ CDN ไม่ใช้ CSS animation
- ไม่แอนิเมต `letterSpacing` และ `fromTo` ที่ใช้ซ้ำต้องใส่ `immediateRender: false` (ถ้าองค์ประกอบเริ่มซ่อน ต้องใส่ `opacity: 1` ในค่าปลายทางด้วย)
- ชื่อร้านยาวต้องไม่ล้นจอ
- ผ่าน `npx hyperframes lint` ไม่มี error และดู `snapshot` ก่อนส่ง
- **ห้ามลอกงานที่ออกแบบให้ร้านอื่น** และห้ามใส่ข้อมูลลูกค้าในไฟล์เทมเพลต
