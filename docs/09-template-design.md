# 9. ออกแบบเทมเพลตเฉพาะร้าน (ต่อจากการสัมภาษณ์ธุรกิจ)

ทุกร้านได้เทมเพลตที่ **ออกแบบใหม่ทั้งหมด ไม่เหมือนร้านอื่น** สร้างจากคำตอบของเจ้าของร้าน
เทมเพลตต้นฉบับ (`templates/review-motion/`) **ไม่ใช่ฐานของการออกแบบ** ใช้เป็นแค่ข้อกำหนดทางเทคนิค (ดูหัวข้อสุดท้าย)

## ลำดับ

1. สัมภาษณ์ธุรกิจเสร็จ ([07-onboarding.md](07-onboarding.md))
2. ถามคำถามออกแบบในไฟล์นี้ (6 หมวด)
3. Claude สรุปคอนเซปต์ออกมาเป็นภาษาคน 1 ย่อหน้า + ตัวอย่างภาพนิ่ง 2–3 แบบ ให้เจ้าของร้านเลือกหรือสั่งแก้
4. สร้างเทมเพลตจริงที่ `templates/<ชื่อร้าน>/` และบันทึกคำตอบที่ `design-brief.md`
5. เปิด PR ให้เจ้าของร้านดู แล้วใช้เทมเพลตนี้เป็นค่าเริ่มต้นของงานตัดคลิปทุกชิ้น

## กติกาการถาม (สำหรับ Claude)

- ใช้ AskUserQuestion **ครั้งละไม่เกิน 4 ข้อ** ตามหมวด
- **ทุกข้อต้องมีตัวเลือก `ข้ามไว้ก่อน` และ `ไม่สะดวกตอบ`** (กติกาเดียวกับการสัมภาษณ์ธุรกิจ)
  - `ข้ามไว้ก่อน` = Claude ตัดสินใจแทนจากโปรไฟล์ธุรกิจ แล้วบอกเจ้าของร้านว่าเลือกอะไรไป
  - `ไม่สะดวกตอบ` = ไม่ถามซ้ำ ให้ Claude ออกแบบเองจากโปรไฟล์ธุรกิจ
- ตัวเลือกที่ให้ในแต่ละข้อเป็น **ตัวอย่างความรู้สึก ไม่ใช่สไตล์สำเร็จรูป** ห้ามเสนอสิ่งที่เคยออกแบบให้ร้านอื่น
- ถ้าตอบว่าชอบแบบไหน ให้ถามต่อว่า "ชอบตรงไหน" แทนการลอกทั้งแบบ
- อ่าน `business-profile.md` ก่อนถาม ไม่ถามซ้ำสิ่งที่รู้แล้ว (เช่น โทนหลัก สีแบรนด์)

## หมวด 1: ตัวตนของร้าน

| # | คำถาม | ตัวเลือก (ตัวอย่าง) |
|---|---|---|
| 1.1 | ถ้าร้านคุณเป็นคน จะเป็นคนแบบไหน | ผู้เชี่ยวชาญที่น่าเชื่อถือ · เพื่อนสนิทที่เป็นกันเอง (พิมพ์เองได้) |
| 1.2 | อยากให้คนดูคลิปจบแล้วรู้สึกอะไร | มั่นใจ อยากลอง · ประทับใจ จำร้านได้ |
| 1.3 | ร้านมีสัญลักษณ์ ลวดลาย หรือของประจำร้านไหม | มี (ส่งรูปโลโก้ / ลวดลาย / ภาพร้านมา) · ไม่มี ให้ Claude คิดให้ |
| 1.4 | มีคำติดปากหรือประโยคประจำร้านไหม | มี (พิมพ์มา) · ไม่มี |

## สิ่งที่ Claude ส่งมอบ

1. **`design-brief.md`**: คำตอบทั้งหมด + คอนเซปต์ 1 ย่อหน้า + เหตุผลของแต่ละการตัดสินใจ
2. **`templates/<ชื่อร้าน>/`**: เทมเพลตใหม่ (build.py + หน้า HTML) ออกแบบจากศูนย์ตาม brief
3. **ภาพตัวอย่าง** 2–3 แบบก่อนสร้างจริง และภาพจากเทมเพลตจริงหลังสร้าง ส่งในแชท (ไม่อัปขึ้น repo)
4. แก้ `business-profile.md` หัวข้อเทมเพลต ให้ชี้ไปที่เทมเพลตของร้าน

## ข้อกำหนดทางเทคนิคที่เทมเพลตใหม่ต้องทำตาม

หน้าตาออกแบบใหม่ได้ทั้งหมด แต่ต้องทำงานกับขั้นตอนเดิมได้ ([04-workflow.md](04-workflow.md)):

- **รับข้อมูลชุดเดิม:** `content.json` (hook, titles, captions, lower_thirds, transitions, end_card), ช็อตจาก `cut_shots.py` (`shots.json` + `--head-pad`), เสียงจาก `mix_audio.sh`, ชื่อและสีจาก `brand.json`
- **คำสั่งเดิม:** `python3 -I templates/<ชื่อร้าน>/build.py <content.json> <โฟลเดอร์โปรเจกต์>`
- **ต้องมีหัวข้อค้างบนจอทุกช่วง** และซับอ่านได้บนพื้นสว่างและพื้นมืด
- ฟอนต์จาก `brand.json` เท่านั้น เผื่อขอบบนให้วรรณยุกต์ไทย
- GSAP จากไฟล์ในเครื่อง ไม่ใช้ CDN ไม่ใช้ CSS animation
- ไม่แอนิเมต `letterSpacing` และ `fromTo` ที่ใช้ซ้ำต้องใส่ `immediateRender: false`
- ชื่อร้านยาวต้องไม่ล้นจอ
- ผ่าน `npx hyperframes lint` ไม่มี error และดู `snapshot` ก่อนส่ง
- **ห้ามลอกงานที่ออกแบบให้ร้านอื่น** และห้ามใส่ข้อมูลลูกค้าในไฟล์เทมเพลต
