# 2. ตั้งค่าเครื่องใหม่ (ทำครั้งเดียว)

ทำตามลำดับ ใช้เวลารวมราว 20–30 นาที ทำจาก iPad ได้ทั้งหมด (ใช้ Safari)

## สิ่งที่ต้องมี

| สิ่งที่ต้องมี | ใช้ทำอะไร |
|---|---|
| บัญชี Claude แบบเสียเงิน (Pro หรือ Max) | ใช้ Claude Code บน cloud (ไม่ต้องซื้อเครดิตแยก ใช้โควตาเดียวกับแชทปกติ) |
| บัญชี GitHub (ฟรี) | เก็บ repo ของคุณเอง |
| Google Drive | เก็บฟุตเทจ เสียงพากย์ เพลง |
| บัญชี ElevenLabs | ถอดเสียงไทยแม่นและเร็ว + พากย์ด้วยเสียง AI (เสียงไทยในคลังและโคลนเสียงต้องซื้อแพ็กเกจ บัญชีฟรีใช้ได้แค่เสียงพื้นฐาน) |

ไม่ต้องมี Mac หรือคอมพิวเตอร์ ไม่ต้องติดตั้งโปรแกรมใดๆ ในเครื่องตัวเอง

## ขั้นที่ 1: สร้าง repo ของคุณเองจากเทมเพลต

1. เปิดหน้า repo ต้นแบบที่ได้รับลิงก์มา
2. กดปุ่มเขียว **Use this template** → **Create a new repository**
3. ตั้งชื่อ repo เช่น `video-studio` และเลือก **Private** (แนะนำ เพราะจะมีข้อมูลร้าน)
4. กด **Create repository**

repo ใหม่เป็นของคุณ 100% ไม่ผูกกับ repo ต้นแบบ แก้อะไรก็ไม่กระทบคนอื่น

> **สำหรับเจ้าของ repo ต้นแบบ:** เปิดให้คนอื่นใช้เป็นเทมเพลตได้ที่ GitHub → repo → **Settings** → **General** → ติ๊ก **Template repository**

## ขั้นที่ 2: เชื่อม Claude กับ GitHub และ Google Drive

1. เปิด https://claude.ai → **Settings** → **Connectors**
2. เชื่อม **GitHub** แล้วติดตั้ง Claude GitHub App ให้ repo ใหม่ของคุณ (ระบบจะพาไปหน้าติดตั้ง)
3. เชื่อม **Google Drive**

## ขั้นที่ 3: สร้าง environment และตั้งค่าเครือข่าย

เครื่อง cloud ต่ออินเทอร์เน็ตได้เฉพาะเว็บที่อนุญาต งานตัดต่อต้องเปิดเว็บต่อไปนี้

1. เปิด https://claude.ai/code ใน **Safari** (แอปบน iPad บางเวอร์ชันหาเมนูนี้ไม่เจอ)
2. เลือก repo ของคุณ → กดชื่อ **environment** ด้านบน → **Edit** (หรือสร้างใหม่)
3. **Network access** → เลือก **Limited** (บางเวอร์ชันชื่อ Custom) → ติ๊ก **Allow package managers**
4. ใส่ใน **Allowed domains** (ทุกตัวต้องมี ยกเว้นที่เขียนว่าไม่บังคับ · ใส่ชื่อเต็มทีละตัว ไม่ใช้ `*`):

| โดเมน | ใช้ทำอะไร |
|---|---|
| `drive.google.com` | ดึงฟุตเทจจาก Drive |
| `drive.usercontent.google.com` | ดาวน์โหลดไฟล์จาก Drive |
| `www.googleapis.com` | API ของ Drive |
| `huggingface.co` | ดาวน์โหลดโมเดลถอดเสียง |
| `cdn-lfs.huggingface.co` | ที่เก็บไฟล์โมเดลถอดเสียง |
| `cas-bridge.xethub.hf.co` | ที่เก็บไฟล์โมเดลถอดเสียง |
| `cas-server.xethub.hf.co` | ที่เก็บไฟล์โมเดลถอดเสียง |
| `us.aws.cdn.hf.co` | ที่เก็บไฟล์โมเดลถอดเสียง |
| `mixkit.co` | ค้นหาเสียงเอฟเฟกต์ (skill `mixkit-sfx`) ไม่บังคับ |
| `assets.mixkit.co` | ดาวน์โหลดเสียงเอฟเฟกต์จาก Mixkit ไม่บังคับ |

5. บันทึก แล้ว **เปิดแชทใหม่** ให้การตั้งค่ามีผล

**ให้ Claude ตั้งให้ (ง่ายกว่า):** เริ่มแชทแรก Claude เช็กเองว่าขาดเว็บไหน แล้วขอเพิ่มทีเดียว คุณแค่กด **อนุญาต** ในหน้าต่างที่ขึ้นมา (มีผลภายในไม่กี่วินาที ไม่ต้องเปิดแชทใหม่)
ข้อ 1–3 (เลือก Limited + Allow package managers) ยังต้องทำเองครั้งแรกถ้า environment ยังไม่ได้สร้าง · ตั้งเองตามตารางนี้เมื่อ Claude ขอเพิ่มไม่ได้

**คีย์ ElevenLabs (ต้องมี):** Claude ขอตอนสัมภาษณ์ข้อ 7.4 ผ่านฟอร์มปลอดภัย หรือใส่เองที่ **Network secrets**: host `api.elevenlabs.io`, header `xi-api-key`
ห้ามพิมพ์คีย์ในแชท และห้ามใส่ใน environment variables (เก็บเป็นข้อความธรรมดา)

คู่มือทางการ: https://code.claude.com/docs/en/cloud-environments#network-access

`cdn.jsdelivr.net` ไม่ต้องเปิด เทมเพลตใช้ไฟล์ในเครื่องแทนแล้ว

## ขั้นที่ 4: ให้ Claude สัมภาษณ์ธุรกิจของคุณ (~5–10 นาที)

เปิดแชทแรกกับ repo ของคุณ แล้วพิมพ์:

> รัน setup แล้วสัมภาษณ์ธุรกิจของผม

Claude จะติดตั้งโปรแกรม แล้วถามเป็นชุด ชุดละไม่เกิน 4 ข้อ รวม 6 หมวด:
ธุรกิจ · ลูกค้า · ภาพลักษณ์แบรนด์ · งานคลิป · เสียงและข้อห้าม · การทำงานร่วมกัน

- ทุกข้อกดเลือกได้ หรือพิมพ์ตอบเองในช่อง Other
- **ทุกข้อมี `ข้ามไว้ก่อน`** (Claude จะถามใหม่ตอนต้องใช้) **และ `ไม่สะดวกตอบ`** (Claude จะไม่ถามซ้ำ ใช้ค่าเริ่มต้นแทน)
- จบแล้ว Claude บันทึกคำตอบลง `business-profile.md` และ `brand.json` แล้วเปิด PR ให้ บอก "เอาเข้า" เพื่อบันทึก
- แก้ทีหลังได้ทุกเมื่อ พิมพ์ "แก้โปรไฟล์ หมวด ___"

รายการคำถามทั้งหมดและค่าเริ่มต้น: [07-onboarding.md](07-onboarding.md)

หลังกรอกโปรไฟล์ แนะนำตั้ง repo เป็น **Private** (Settings → General → Danger Zone → Change visibility)

## ขั้นที่ 4b: ออกแบบเทมเพลตของร้านคุณ (~10–20 นาที)

ต่อจากการสัมภาษณ์ พิมพ์:

> ออกแบบเทมเพลตของร้านผม

Claude จะถามเรื่องตัวตนร้าน แรงบันดาลใจ ตัวหนังสือ การเคลื่อนไหว การเปิด-ปิดคลิป (ข้ามข้อไหนก็ได้)
ส่งคลิปหรือภาพตัวอย่างที่ชอบมาได้ทุกเมื่อ แล้ว Claude จะออกแบบเทมเพลตใหม่ที่เป็นของร้านคุณเท่านั้น
พร้อมภาพตัวอย่างให้เลือกก่อนสร้างจริง รายละเอียด: [09-template-design.md](09-template-design.md)

## ขั้นที่ 5: ทดสอบ

1. อัปฟุตเทจสั้นๆ 3–5 ไฟล์ และเสียงพากย์ 15–20 วินาที ใส่โฟลเดอร์เดียวใน Drive
2. ส่งลิงก์โฟลเดอร์ให้ Claude พร้อมสคริปต์บทพากย์
3. ถ้าได้คลิปกลับมา แปลว่าตั้งค่าครบแล้ว

## ถ้าติดปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| Claude ดึงไฟล์จาก Drive ไม่ได้ (403) | ยังไม่ได้เพิ่มโดเมน Drive หรือยังไม่เปิดแชทใหม่ / ตั้งไฟล์เป็น "ทุกคนที่มีลิงก์ดูได้" |
| ถอดเสียงไม่ได้ (403, xethub) | ยังไม่ได้เพิ่ม `*.hf.co` |
| Claude มองไม่เห็น repo | ยังไม่ได้ติดตั้ง Claude GitHub App ให้ repo นั้น |
| เปิดเมนู environment ในแอปไม่เจอ | ใช้ Safari เปิด claude.ai/code |

## งานที่ Claude ทำ Git ให้

- ทุกงานทำบน branch ใหม่ (`claude/...`) แล้วเปิด Pull Request (คำขอรวมงานเข้าฉบับหลัก)
- คุณบอก "เอาเข้า" Claude จะรวม PR เข้า `main` ให้
- งานที่ยังไม่ push จะหายไปพร้อมเครื่อง cloud
