# 8. ตัดต่อด้วยระบบนี้ เทียบกับตัดต่อเอง

เอกสารนี้สรุปว่าการใช้ชุดเครื่องมือนี้ต่างจากการตัดต่อเองแค่ไหน และผู้ใช้ได้อะไร
ตัวเลขฝั่งระบบมาจากงานทดสอบจริง ตัวเลขฝั่ง "ตัดต่อเอง" เป็นค่าประมาณสำหรับงานแบบเดียวกัน:
คลิปรีวิวแนวตั้ง 60 วินาที จากฟุตเทจ 4K ~60 ไฟล์ มีซับภาษาไทย หัวข้อ ทรานสิชัน และเพลง

## 1. เวลา

| ขั้น | ตัดต่อเอง (ประมาณ) | ระบบนี้ |
|---|---|---|
| ดูฟุตเทจ คัดช็อต | 30–60 นาที | ~5 นาที (อัตโนมัติ) |
| ตัดต่อ เรียงช็อต | 30–60 นาที | ~3 นาที |
| ใส่ซับภาษาไทย | 20–40 นาที | ~1–2 นาที (0 ถ้าส่งสคริปต์มา) |
| หัวข้อ โมชั่น ทรานสิชัน | 30–60 นาที | อยู่ในเทมเพลตแล้ว |
| render / export | 5–10 นาที | ~7–8 นาที |
| **รวม** | **~2–4 ชั่วโมง** | **~20 นาที** |

ส่วนที่สำคัญกว่าเวลาเครื่องคือ **เวลาของเจ้าของงาน: เหลือราว 5–10 นาทีต่อคลิป**
(ส่งลิงก์และสคริปต์ ดูแผน สั่งแก้) ระหว่างที่ระบบทำงาน เจ้าของงานไปทำอย่างอื่นได้

## 2. สิ่งที่ผู้ใช้ได้รับ

| ได้อะไร | รายละเอียด |
|---|---|
| ไม่ต้องมีทักษะตัดต่อ | สั่งเป็นภาษาพูดจาก iPad หรือมือถือ ไม่ต้องเปิดคอม ไม่ต้องลงโปรแกรม |
| ใช้ไฟล์ 4K ต้นฉบับได้ | ไม่ต้องย่อไฟล์ก่อนส่ง ดึงตรงจาก Google Drive |
| แบรนด์สม่ำเสมอทุกคลิป | ฟอนต์ สี ชื่อร้าน ปุ่มชวน มาจาก `brand.json` ไฟล์เดียว |
| คุณภาพไม่ตก | กฎจากบทเรียนบังคับใช้ทุกงาน: ไม่ใช้ช่วงกล้องหัน, หัวข้อค้างบนจอ, ซับตรงเสียง, ภาพตรงคำพูด |
| ระบบรู้จักธุรกิจ | ใช้ผลสัมภาษณ์ครั้งแรก ([07-onboarding.md](07-onboarding.md)) เขียนประโยคเปิด เลือกโทน และเช็กข้อห้ามให้อัตโนมัติ |
| คุมงานได้ก่อน render | สตอรีบอร์ดมีเลขช็อต สั่งแก้ง่าย เช่น "เปลี่ยนช็อต 7" |
| ส่งต่อให้คนอื่นได้ | คนใหม่ตั้งค่าจากเทมเพลตได้ในราว 30 นาที ได้ระบบเดียวกันทั้งหมด |

## 3. สิ่งที่ตัดต่อเองยังทำได้ดีกว่า

- **ความคิดสร้างสรรค์เฉพาะคลิป:** มุกตลก จังหวะตัดตามบีตเพลง เทรนด์ใหม่ คนที่เก่งตัดต่อยังทำได้ดีกว่าเทมเพลต
- **ความหลากหลายของลูกเล่น:** ระบบมีทรานสิชันและสไตล์จำกัด ลุคใหม่ต้องพัฒนาเทมเพลตเพิ่ม
- **เห็นผลทันที:** ตัดต่อเองเห็นผลทุกวินาที ระบบต้องรอ render ~8 นาทีต่อการแก้หนึ่งรอบ
- **เพลงเทรนด์ในแอป:** เพลงฮิตใน TikTok / CapCut ใส่ได้ในแอปเท่านั้น ระบบใช้ได้แค่ไฟล์เพลงที่ส่งมา

## 4. ข้อจำกัดที่ต้องรู้

- **ซับ:** ถ้าไม่มีสคริปต์ โมเดลถอดเสียงอาจฟังผิดบางคำ ต้องตรวจทุกครั้ง
- **ซับฝังหลังตัวคน (`embedded-captions`):** ใช้ไม่ได้กับคลิปเสียงพากย์หลายช็อต
- **การตั้งค่าครั้งแรก:** ต้องทำผ่าน Safari และเปิดเครือข่ายให้ถูก เป็นจุดที่คนใหม่ติดบ่อย
- **ค่าใช้จ่าย:** ต้องมีแพ็กเกจ Claude แบบเสียเงิน งานแต่ละคลิปกินโควตาพอสมควร
- **ยังต้องมีคนตัดสินใจ:** ระบบเลือกช็อตจากภาพนิ่งและคะแนนเทคนิค "ช็อตที่สวยที่สุด" บางครั้งเจ้าของงานต้องชี้เอง

## 5. เหมาะกับใคร

| เหมาะมาก | อาจไม่คุ้ม |
|---|---|
| ธุรกิจที่ต้องลงคลิปสม่ำเสมอ (สัปดาห์ละหลายคลิป) | คนที่ตัดต่อเก่งอยู่แล้วและสนุกกับการตัด |
| คลิปรูปแบบซ้ำ เช่น รีวิว ก่อน-หลัง ให้ความรู้ | คลิปที่ต้องสร้างสรรค์ใหม่ทุกครั้ง หรือตามเทรนด์รายวัน |
| เจ้าของที่ไม่มีเวลาหรือไม่มีทักษะตัดต่อ | งานที่ต้องแก้ละเอียดหลายรอบแบบเห็นผลทันที |

## สรุป

ระบบนี้ไม่ได้มาแทนนักตัดต่อฝีมือดี แต่ **เปลี่ยนการตัดต่อจากงาน 2–4 ชั่วโมงที่ต้องลงมือเอง
ให้เหลือการสั่งงานและตรวจงาน ~10 นาที** และได้คลิปที่คุณภาพและแบรนด์สม่ำเสมอทุกชิ้น
คุ้มที่สุดกับธุรกิจที่ผลิตคลิปรูปแบบเดิมซ้ำๆ เป็นประจำ
